# Irrefutable proof

**What it is:**

Proof, not a claim. The agent has to show evidence that the change works, such as a passing test, real output or a screenshot, rather than say it does.

**When / why:**

The agent says "fixed" or "done", and you suspect it hasn't run anything. Ask for proof so it has to run the code and bring back evidence you can check.

**Exact prompt:**

> Give me irrefutable proof this works now

**Why this packs more than a tip:**

"Proof" brings in the whole idea of verification. "Irrefutable" rules out vibes and self-assessment, so the agent has to reach for an outside check.
