# Fail fast / throw

**Exact prompt:**

> if the environment variable isn't present, throw

**Why denser than a tip:**

Agents avoid crashing. Naming fail-fast as a direct order flips that default.

**Source:**

- Person: Matt Pocock
- Date: 24 Aug 2026
- URL: https://x.com/mattpocockuk/status/2091806367233212872

**Optional gloss (source’s words):**

> Something agents have a massive problem with is failing fast
>
> They're cowards, they never want to be responsible for a crash
>
> I've lost count of how many times I've said "if the environment variable isn't present, throw"
