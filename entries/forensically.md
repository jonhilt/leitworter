# Forensically

**What it is:**

Evidence-first difference analysis. Treat the gap like a crime scene. No vibe pass.

**When / why:**

Two things should match, design system vs implementation, and you need every delta named. "Looks close" is not enough.

**Exact prompt:**

> forensically analyse the difference between [A] and [B]

Example from lived use:

> forensically analyse the difference between the component in our design system and the implementation of that component

**Why denser than a tip:**

Names a forensic exam: evidence-first, exhaustive, no vibe pass. Not "compare these carefully."
