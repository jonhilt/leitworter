# Competing theories

**What it is:**

Multiple working hypotheses. The agent has to come up with several possible causes and test every one of them, rather than run with the first.

**When / why:**

Something is slow, flaky or behaving in a way nobody can explain, and the first guess is tempting. Ask for four theories and a check on all four, so the agent can't lock onto the first plausible cause and stop. For example: "The dashboard takes 8 seconds to load. Give me 4 theories on why this is slow, then check all four."

**Exact prompt:**

> Give me 4 theories on why this is slow, then check all four.

**Why this packs more than a tip:**

It forces a comparison in the problem space. The agent holds several hypotheses side by side and tests each one, so the evidence picks the cause, not the first idea. [What would make this wrong](what-would-make-this-wrong.md) tests one answer and [Irrefutable proof](irrefutable-proof.md) checks a fix. This one comes earlier, before there is an answer to test.
