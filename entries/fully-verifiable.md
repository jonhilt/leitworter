# Fully verifiable

**What it is:**

A design bar that makes the change itself checkable by a human rather than a claim from the agent.

**When / why:**

The agent is about to ship something you cannot really check: a signup flow, a click path through the UI. Ask how to make the change fully verifiable, so it redesigns the work around real checks instead of a "done" report.

**Exact prompt:**

> How do we make this change fully verifiable?

**Why this packs more than a tip:**

It names the verifiability bar so the agent redesigns the change for real checks, signing up for services and clicking through the UI, instead of claiming done. [Irrefutable proof](irrefutable-proof.md) asks for evidence after the fact. This one pulls verification into how the change is made.
