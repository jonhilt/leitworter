# What would make this wrong

**What it is:**

Falsification. The agent has to name the conditions under which its answer would be false, then check them.

**When / why:**

The agent hands you a confident diagnosis or plan that nobody has checked. Ask what would have to be true for it to be wrong, so it tests its own claim before you build on it.

**Exact prompt:**

> What would have to be true for this to be wrong?

**Why this packs more than a tip:**

It brings in falsifiability, so the agent looks for counter-evidence instead of more support for its answer. That catches the confident answer nobody checked.
