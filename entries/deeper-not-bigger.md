# Deeper, not bigger

**What it is:**

A forced comparison between depth and scope. Do the task the way a field-leading expert would, using their raw material, methods and outside checks, instead of doing more of it.

**When / why:**

You've got a competent but shallow result, like a deck of markdown tables or a fix for the symptom. You want the expert version, and you don't want the agent to just add more sections.

**Exact prompt:**

> I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I'm not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

**Why this packs more than a tip:**

"Deeper vs bigger" stops the default response to "make it better", which is to add more. The agent goes down a level instead: raw data, real tools, and an outside judge.
