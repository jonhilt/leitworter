# Hyper intuitively, bottoms up

**What it is:**

Bottom-up explanation. Understanding is built from first principles upward, concrete before abstract, in small visual steps, instead of starting top-down with jargon.

**When / why:**

You pick up an unfamiliar part of a codebase, an algorithm or a concept, and the agent's first explanation is a wall of terms you don't have yet. Ask it to explain hyper intuitively, bottoms up, so it starts from the smallest concrete pieces and builds up one step at a time. For example: "explain how the React reconciler decides what to re-render, hyper intuitively, bottoms up, with simple step-by-step diagrams". It pairs well with asking for an animated or visual explainer.

**Exact prompt:**

> explain this hyper intuitively bottoms up with the most simple step by step animations so i really understand concretely

**Why this packs more than a tip:**

"Bottoms up" names a direction of explanation, so the agent builds from concrete pieces toward the abstraction instead of from the abstraction down. "Explain it simply" can't do that.
