# Tufte

**What it is:**

Edward Tufte's approach to visual design: show the data, cut everything that isn't data.

**When / why:**

The agent builds a chart, dashboard or report page and it comes out cluttered, with heavy borders, gradients and a legend you have to hunt for. Ask for something Tufte would be proud of, so it strips the decoration and lets the numbers carry the page.

**Exact prompt:**

> Make it look like Edward Tufte would be proud of it.

**Why this packs more than a tip:**

One name pulls in a whole design approach: high data-ink ratio, no chartjunk, small multiples, dense but readable displays. "Make it cleaner" can't do that.
