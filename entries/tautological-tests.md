# Tautological tests

**Exact example (standards line a review skill can pick up):**

```bash
echo "Tautological tests considered harmful." >> CODING_STANDARDS.md
```

From then on, `/code-review` (or equivalent) can reject tests that only restate the implementation.

**Why denser than a tip:**

Names a known bad pattern in one line so review agents delete echo-the-impl tests.
