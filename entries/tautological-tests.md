# Tautological tests

**Exact example (a standards line review can pick up):**

```bash
echo "Tautological tests considered harmful." >> CODING_STANDARDS.md
```

After that, `/code-review` (or your review skill) can reject tests that only echo the implementation.

**Why denser than a tip:**

One line names the bad pattern. Review agents can delete those tests on sight.
